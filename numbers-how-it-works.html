How Number Pegs Work

The Major System converts numbers into consonant sounds, which you then turn into memorable words. Each digit 0-9 maps to a specific consonant sound. Vowels and the letters W, H, Y don't count — they're just filler to make real words. Two-digit numbers use two consonant sounds combined into one word.

How Two-Digit Numbers Work

For two-digit numbers, the tens digit gives the first consonant sound and the ones digit gives the second. Vowels are added to form a real word.

42 → RaiN
4 = R, 2 = N → R_N → RaiN
67 → BoaT
6 = B, 7 = T → B_T → BoaT
85 → CHeF
8 = CH, 5 = F → CH_F → CHeF

Single Digits (0-9)

Single-digit numbers use just one consonant sound: 0 = Zoo, 1 = aLe, 7 = Tea, 9 = Goo.
